☁️ 클라우드 배포 전략

Google Cloud Platform (GCP) 서버리스 배포

Scale-to-Zero 비용 절감과 전 세계 초고속 서빙을 위한 무중단 아키텍처

1
Google Cloud Run (백엔드 서버리스 컨테이너)
Node.js 멀티에이전트 서버를 컨테이너화하여 서울 리전(asia-northeast3)에 배포, 트래픽 0일 때 비용 0원 유지
2
Firebase Hosting / Cloud CDN (초고속 프론트엔드)
React 18 빌드 정적 자원을 글로벌 엣지 CDN에 분산 캐싱하여 0.1초대 초기 로딩 속도 달성
3
GCP Secret Manager (보안 키 관리) & CI/CD
Gemini API Key를 런타임에 암호화 주입하고 GitHub Actions로 PR 승인 시 자동 무중단 배포
